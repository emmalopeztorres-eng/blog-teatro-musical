# Mundo Teatro Musical

Revista digital dedicada al teatro musical argentino e internacional.

## Secciones
- Actualidad y noticias
- Cartelera
- Entrevistas
- Críticas y análisis
- Historia del teatro musical
- Formación
- Producción y backstage
- Diseño escénico: iluminación, sonido y escenografía
- Broadway y West End
- Teatro musical argentino

## Estructura
- `index.html`: portada y navegación.
- `styles.css`: identidad visual y diseño responsive.
- `app.js`: navegación móvil e interacciones.

## Publicación con GitHub Pages
En el repositorio, entrar a **Settings → Pages**. En **Build and deployment**, elegir **Deploy from a branch**, seleccionar `main` y la carpeta `/(root)`, y guardar.

El contenido editorial de esta primera versión es introductorio. Las noticias, críticas, entrevistas y datos de cartelera deberán incorporarse con fecha, autoría y fuentes verificables antes de presentarse como información actual.
